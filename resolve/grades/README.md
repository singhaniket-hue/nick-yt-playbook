# PowerGrade slot

Place the channel PowerGrade at `crowley_v1.drx` after exporting it from the
Resolve Gallery. When it is present at compile time, its checksum becomes part
of the immutable style contract; the installer copies it to the user's
RabbitHole support directory and handoff packages include it. The runner
applies it only to the declared archival V1 clips on a newly imported build.

The repository's `.cube` LUT is the deterministic fallback. Do not represent
the LUT as containing grain or a vignette: those spatial effects live on the
editable V4/Fusion layer.
